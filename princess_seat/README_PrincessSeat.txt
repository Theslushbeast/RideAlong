Ride Along - Princess Seat (OAR add-on)
=======================================
Female passengers riding behind you sit side-saddle. You and everyone else keep the normal riding animations.

REQUIREMENTS
- Ride Along
- Open Animation Replacer
- YY Anim Replacer - Princess' Horse Riding by yukl (SE port: nexusmods.com/skyrimspecialedition/mods/28451)
  Its animations are not included. You copy them in yourself (one folder, below).

INSTALL
1. Install Ride Along, this add-on, and YY Anim Replacer - Princess' Horse Riding.
2. Open the YY mod's files and find this folder:
      Meshes\actors\character\animations\horse_rider
   (MO2: right-click the YY mod > Open in Explorer.)
3. Copy the whole horse_rider folder (18 .hkx files) into this add-on's folder:
      meshes\actors\character\animations\OpenAnimationReplacer\RideAlongPrincess\Passenger\
   so you end up with ...\RideAlongPrincess\Passenger\horse_rider\idle.hkx and the rest.
   (MO2: right-click this add-on > Open in Explorer.)
   Do NOT copy the sharedkillmoves folder.
4. Disable / untick YY Anim Replacer. If it stays on, everyone (you included) rides side-saddle.
   With the files copied, only Ride Along's female passengers use them.

Without the animations, Ride Along simply seats female passengers astride as usual.
Seat position and turn: RideAlong.ini [Princess], or SKSE Menu Framework > Ride Along.

Credits: side-saddle animations by yukl (YY Anim Replacer - Princess' Horse Riding).
